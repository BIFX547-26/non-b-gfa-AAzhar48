# Package Datasets Documentation

## Overview

The **nonBgfa** package includes curated test data designed to validate the package functionality and serve as examples for users.

## gfa_test: Example DNA Test Sequence

### Location
- **File**: `data-raw/gfa_test.fasta`
- **Accessible via**: `system.file("extdata", "gfa_test.fasta", package = "nonBgfa")`

### Description

A 6,280 bp DNA test sequence containing a comprehensive collection of non-B DNA-forming motifs. This sequence was carefully designed (or selected) to include all seven major motif types that the GFA algorithm can detect.

### Characteristics

| Property | Value |
|----------|-------|
| Length | 6,280 bp |
| Format | FASTA |
| Header | ">Test Sequence" |
| Composition | ACGT + occasional N |
| Completeness | All 7 motif types present |

### Motif Content

When analyzed with default parameters, the sequence yields exactly **42 non-B DNA motifs** distributed as:

| Motif Type | Count | Files |
|-----------|-------|-------|
| A-Phased Repeats (APR) | 1 | `gfa_baseline_APR.gff`, `gfa_baseline_APR.tsv` |
| Direct Repeats (DR) | 4 | `gfa_baseline_DR.gff`, `gfa_baseline_DR.tsv` |
| Inverted Repeats (IR) | 14 | `gfa_baseline_IR.gff`, `gfa_baseline_IR.tsv` |
| G-Quadruplexes (GQ) | 7 | `gfa_baseline_GQ.gff`, `gfa_baseline_GQ.tsv` |
| Mirror Repeats (MR) | 5 | `gfa_baseline_MR.gff`, `gfa_baseline_MR.tsv` |
| Short Tandem Repeats (STR) | 7 | `gfa_baseline_STR.gff`, `gfa_baseline_STR.tsv` |
| Z-DNA (Z) | 4 | `gfa_baseline_Z.gff`, `gfa_baseline_Z.tsv` |
| **TOTAL** | **42** | **14 baseline files** |

### Usage in Tests

The `gfa_test.fasta` sequence is used throughout the package test suite:

#### 1. Baseline Comparison Tests (`tests/testthat/test-equivalence.R`)
```r
# Load baseline results
baseline_gq <- read.table(
  system.file("extdata", "baseline/gfa_baseline_GQ.gff", 
              package = "nonBgfa"),
  sep = "\t", header = FALSE
)

# Analyze test sequence
test_fasta <- system.file("extdata", "gfa_test.fasta", 
                          package = "nonBgfa")
results <- gfa_analyze(fasta_file = test_fasta)

# Compare
expect_equal(nrow(results$gq_gff), nrow(baseline_gq))
```

#### 2. Format Validation Tests
```r
# Verify GFF format compliance
expect_true(ncol(results$gq_gff) >= 9)
expect_true(all(results$gq_gff$start < results$gq_gff$end))
```

#### 3. Integration Tests
```r
# Run full analysis pipeline
results <- gfa_analyze(
  fasta_file = system.file("extdata", "gfa_test.fasta", 
                           package = "nonBgfa"),
  output_prefix = tempfile()
)

# Verify all expected motif types are present
expect_true(!is.null(results$apr_gff))
expect_true(!is.null(results$dr_gff))
# ... etc for all 7 types
```

## Baseline Output Files

### Location
Directory: `tests/testthat/data/baseline/`

### Contents

14 reference output files generated by running the original GFA command-line tool on `gfa_test.fasta`:

```
gfa_baseline_APR.gff     # 1 record
gfa_baseline_APR.tsv     # 1 record
gfa_baseline_DR.gff      # 4 records
gfa_baseline_DR.tsv      # 4 records
gfa_baseline_GQ.gff      # 7 records
gfa_baseline_GQ.tsv      # 7 records
gfa_baseline_IR.gff      # 14 records
gfa_baseline_IR.tsv      # 14 records
gfa_baseline_MR.gff      # 5 records
gfa_baseline_MR.tsv      # 5 records
gfa_baseline_STR.gff     # 7 records
gfa_baseline_STR.tsv     # 7 records
gfa_baseline_Z.gff       # 4 records
gfa_baseline_Z.tsv       # 4 records
```

### Command Used to Generate

```bash
cd tests/testthat/data
./gfa -skipWGET -seq gfa_test.fasta -out gfa_baseline
```

### File Format

#### GFF Files
Tab-separated values with 9 columns:
1. `seqname` - Sequence identifier (typically "Test Sequence")
2. `source` - Data source (always "GFA")
3. `feature` - Motif type identifier
4. `start` - Start position (1-based)
5. `end` - End position (inclusive)
6. `score` - Detection score
7. `strand` - DNA strand (+ or -)
8. `frame` - Reading frame (. for N/A)
9. `attributes` - Semicolon-separated key=value pairs

**Example GFF record:**
```
Test Sequence	GFA	G4	1234	1256	.	+	.	islands=1;runs=4;max=3;composition=12G/3A
```

#### TSV Files
Tab-separated values with extended columns:
- Columns 1-9: Same as GFF format
- Additional columns:
  - `islands`: Number of motif islands
  - `runs`: Number of runs within island
  - `max`: Maximum run length in island
  - `composition`: Nucleotide breakdown (e.g., "12G/3A")
  - `sequence`: The actual detected motif sequence

**Example TSV record:**
```
Test Sequence	GFA	G4	1234	1256	.	+	.	islands=1	...	composition	GGGGAGGGGAGGGG
```

## Data Quality Assurance

### Validation Tests

The package includes comprehensive tests validating the included datasets:

1. **File Existence Tests** (`tests/testthat/test-equivalence.R`)
   - Verifies all baseline files exist and are readable
   - Checks FASTA file format compliance

2. **Format Validation Tests**
   - GFF files have exactly 9 tab-separated columns
   - Start positions are less than end positions
   - Coordinates are positive integers
   - TSV files include additional columns with expected content

3. **Baseline Completeness Tests**
   - Confirms all 7 motif types have baseline files
   - Verifies both GFF and TSV versions exist
   - Checks exact motif counts match expected values

4. **Integration Tests**
   - Runs the analysis pipeline on test data
   - Compares output to baseline files
   - Validates equivalence of results

### Expected Test Output

When tests pass, you should see:
```
✓ Baseline files exist for all motif types (14 files)
✓ GFF format validation passes
✓ TSV format validation passes
✓ Coordinate validity checks pass
✓ Motif counts match baseline (42 total)
✓ All 7 motif types represented
```

## Using Test Data in Your Own Tests

### Example 1: Load Baseline for Comparison
```r
test_that("My function matches baseline", {
  # Load baseline
  baseline <- read.table(
    system.file("extdata", "baseline/gfa_baseline_GQ.gff",
                package = "nonBgfa"),
    sep = "\t", header = FALSE, as.is = TRUE
  )
  
  # Run analysis
  results <- gfa_analyze(
    fasta_file = system.file("extdata", "gfa_test.fasta",
                            package = "nonBgfa")
  )
  
  # Compare
  expect_equal(nrow(results$gq_gff), nrow(baseline))
  expect_equal(results$gq_gff$V4, baseline$V4)  # Start positions match
})
```

### Example 2: Create Minimal Test Suite
```r
test_that("All motif types can be detected", {
  fasta <- system.file("extdata", "gfa_test.fasta", 
                       package = "nonBgfa")
  results <- gfa_analyze(fasta_file = fasta)
  
  # Verify all types detected
  expect_true(nrow(results$apr_gff) > 0)
  expect_true(nrow(results$dr_gff) > 0)
  expect_true(nrow(results$ir_gff) > 0)
  expect_true(nrow(results$gq_gff) > 0)
  expect_true(nrow(results$mr_gff) > 0)
  expect_true(nrow(results$str_gff) > 0)
  expect_true(nrow(results$z_gff) > 0)
})
```

## Adding New Test Data

To add additional test sequences to the package:

1. **Create FASTA file** in `data-raw/`
2. **Generate baseline** with original GFA:
   ```bash
   ./gfa -skipWGET -seq your_sequence.fasta -out baseline
   ```
3. **Add to tests**: Copy baseline files to `tests/testthat/data/baseline/`
4. **Create test cases** in `tests/testthat/test-custom.R`
5. **Document** in this file under new section
